# Alpamys | Түркістан қонақүйі

Қазақша және орысша қонақүй сайты. Компьютерден көру үшін архивті ашып, `index.html` файлын браузерде ашыңыз.

## GitHub Pages-те жариялау

1. GitHub-та жаңа репозиторий ашыңыз. Мысалы, `alpamys-hotel`.
2. **Add file → Upload files** арқылы архивтің ішіндегі файлдарды репозиторийдің түбіріне жүктеңіз. `index.html`, `style.css`, `site.js`, `assets/`, `.nojekyll` және `README.md` бір деңгейде орналасуы керек. Өзгерісті **Commit changes** түймесімен сақтаңыз.
3. Репозиторийде **Settings → Pages** бөліміне кіріңіз. **Source** мәзірінен **Deploy from a branch**, одан кейін `main` және `/(root)` таңдап, **Save** басыңыз.
4. Жариялау аяқталғанда сайт сілтемесі сол **Pages** бөлімінде шығады. Мысалы, `https://username.github.io/alpamys-hotel/`.

[GitHub Pages нұсқаулығы](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Сайтты өңдеу

- `index.html` — қазақша мәтін, байланыс деректері және бет құрылымы.
- `style.css` — дизайн және телефон экранына бейімдеу.
- `site.js` — орысша мәтін, фотогалерея және WhatsApp сұрауы. Формадан жіберілген сұрауды қонақүй WhatsApp-та қарайды.
- `assets/` — сайттың суреттері.

Архивтегі мекенжай — Қожанов көшесі, 43. Қонақүйдің байланыс бетінде 21 деп көрсетілген. Жариялау алдында қонақүйден мекенжайды нақтылаңыз. Мекенжай өзгерсе, `index.html` файлындағы қазақша мәтін мен карта сілтемесін және `site.js` файлындағы орысша мәтінді жаңартыңыз. [Қонақүйдің байланыс беті](https://alpamis.kz/contact-us/)
